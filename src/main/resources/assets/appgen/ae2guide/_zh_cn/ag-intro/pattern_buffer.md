# 样板缓存器

<BlockImage id="appgen:pattern_buffer" scale="8" />

样板缓存器是一种容器，其能够存储样板栏位所放置的样板的原料。

## 容量

样板缓存器对每一个栏位都有容量限制。容量取决于原料的类型，见下表。

| 原料类型       |  每格容量（默认） |
|------------|----------:|
| 物品         |     1,024 |
| 流体         |     1,024 |
| FE         | 1,048,576 |
| 化学品 （通用机械） |     1,024 |
| 魔力 （新生魔艺）  |     1,000 |
| 魔源 （新生魔艺）  |     1,000 |

## 升级

样板缓存器支持以下[升级](ae2:items-blocks-machines/upgrade_cards.md)：

-   <ItemLink id="ae2:capacity_card" /> 使样板缓存器的容量上限翻倍，最多为原容量的1600%。
-   <ItemLink id="ae2:redstone_card" /> 让样板缓存器能够输出红石信号，信号的具体行为由下方的“保持信号”设置决定。

### 保持信号

安装 <ItemLink id="ae2:redstone_card" /> 后，工具栏中会新增“保持信号”按钮，共有三种模式：

| 模式     | 红石信号                    | 取出（从缓存器中取出） | 放入（存入缓存器）  |
|--------|-------------------------|-------------|------------|
| OFF    | 在满足样板配方期间输出。            | 允许。         | 允许。        |
| ON     | 从配方被满足开始，一直输出到缓存器被清空为止。 | 允许。         | 允许。        |
| LOCKED | 与 ON 相同。                | 在配方被满足前锁定。  | 在配方被满足后锁定。 |

## 删除已存储的内容

**鼠标中键点击**存储栏位，会弹出确认对话框，确认后删除该栏位中存储的内容。

**Shift + 鼠标中键点击**则以整个缓存器为目标，而不是被点击的栏位。

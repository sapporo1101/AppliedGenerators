# Stack Smelting Card

<ItemImage id="appgen:stack_smelting_card" scale="4" />

The Stack Smelting Card can be installed in the <ItemLink id="appgen:smelter" /> to allow it to smelt entire stacks of items at once, rather than one item at a time.

When installed, the Smelter will attempt to smelt as many items as possible considering the output space available.

Every smelting operation consumes the same amount of AE as smelting a single item 64 times, resulting in 1280 AE/t, regardless of the number of items smelted in that operation.
